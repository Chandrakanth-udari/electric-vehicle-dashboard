# Electric Vehicle Population Data Analysis

## Project Overview

This project analyzes the population of electric vehicles (EVs) using a dataset containing information about various EVs. The analysis is presented through an interactive dashboard created in Tableau. The goal of this project is to provide insights into EV trends, including distribution by location, type, and manufacturer.

## Dataset

The dataset used for this analysis is `Electric_Vehicle_Population_Data.csv`. Due to its large size (> 25MB), it is not hosted directly in this repository.

* **Download the dataset:** You can download the full dataset from [**https://drive.google.com/file/d/1W-azENhC_mSXyedVtx1Ld0VXksRnnvBH/view?usp=drive_link**].

The dataset contains detailed information about electric vehicles, including:
- **VIN (1-10)**: Vehicle Identification Number
- **County, City, State, Postal Code**: Geographic location of the vehicle
- **Model Year, Make, Model**: Vehicle details
- **Electric Vehicle Type**: Categorization of the EV (e.g., Battery Electric Vehicle (BEV), Plug-in Hybrid Electric Vehicle (PHEV))
- **Clean Alternative Fuel Vehicle (CAFV) Eligibility**: Eligibility for clean fuel incentives
- **Electric Range**: The range of the EV on a single charge
- **Base MSRP**: Manufacturer's Suggested Retail Price
- **Legislative District, DOL Vehicle ID, Vehicle Location, Electric Utility, 2020 Census Tract**: Additional details for a more granular analysis.

## Dashboard

The analysis is visualized in an interactive Tableau dashboard. The dashboard provides a comprehensive view of the EV population data, featuring key metrics and visualizations, such as:
- Total number of vehicles
- Average electric range
- Breakdown of vehicle types (BEV vs. PHEV)
- Vehicle distribution by model year
- Vehicle distribution by state
- Top manufacturers and models
